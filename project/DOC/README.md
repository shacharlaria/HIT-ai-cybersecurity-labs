Hybrid SOC Threat Detector with MITRE ATT&CK STIX Integration

An advanced, containerized Hybrid Security Operations Center (SOC) threat detection system developed as an academic semester project at HIT (Holon Institute of Technology) as part of the Artificial Intelligence-Driven Cybersecurity course.

The framework addresses modern SOC alert fatigue and evasive threats by unifying deterministic signature-based log parsing with an unsupervised Isolation Forest machine learning model. Detected anomalies are dynamically enriched and mapped against the MITRE ATT&CK STIX standard in real time.

📌 Executive Summary & Research Motivation

Modern enterprise Security Operations Centers face two core operational bottlenecks:

Alert Fatigue: High volumes of alerts generated by brittle rule sets overwhelm security analysts with false positives.

Evasion & Zero-Day Threats: Static signature-only mechanisms fail against novel attack vectors, subtle reconnaissance, and polymorphic behaviors.

This project delivers a multi-tiered detection engine deployed in an isolated container environment. It blends rapid deterministic pattern matching with unsupervised machine learning to isolate statistical outliers in network traffic. Furthermore, it automatically correlates each finding with structured MITRE ATT&CK STIX threat bundles, delivering actionable threat intelligence directly to SOC operators.

🏛️ System Architecture

The entire platform is orchestrated through Docker Compose and consists of three decoupled services:

1. Attack & Traffic Simulator (simulator.py)

Continuously generates cyclic operational logs and enterprise network traffic.

Simulates multi-stage attack scenarios including network port scans, brute-force attempts, and anomalous IP connection patterns to benchmark detector resilience under stress.

2. Hybrid Detector Engine (detector.py)

Deterministic Signature Engine: Rapidly cross-references streaming logs against predefined malicious patterns and known attack vectors.

Unsupervised Machine Learning (Isolation Forest): Extracts multidimensional IP behavioral feature vectors (connection rate, port entropy, target diversity) and isolates anomalous activity without requiring labeled historical training data.

MITRE ATT&CK STIX Parser: Parses structured JSON threat bundles (enterprise-attack-mini.json) to resolve techniques, tactic classifications (e.g., Discovery, Credential Access), and evidence logs.

3. Operational SOC Dashboard (dashboard.py)

Built using Streamlit to deliver an interactive web-based command-and-control interface.

Visualizes real-time telemetry, operational severity breakdowns, detailed findings tables with deep-linked MITRE ATT&CK references, and live quantitative research evaluation metrics.

📊 Academic Evaluation & Quantitative Metrics

The framework was empirically validated against simulated enterprise workloads containing over 60 multi-vector security findings. The system achieves a high-performance balance between sensitivity and alert fidelity:

Precision (0.8657): Demonstrates high alert accuracy, ensuring that detected events represent genuine security threats and drastically minimizing analyst fatigue.

Recall (0.9667): Confirms near-complete attack surface coverage, identifying practically all malicious behaviors and stealth attempts without critical misses.

F1-Score (0.9134): The harmonic mean reflects an optimal operational balance between precision and sensitivity.

False Positive Rate / FPR (0.1667): Maintains a low false-alarm threshold in noisy network environments.

🚀 Quick Start & Installation

Prerequisites

Docker Engine (v20.10 or higher)

Docker Compose (v2.0 or higher)

Running the Environment

Clone the repository and navigate to the project directory:

git clone https://github.com/shacharlaria/HIT-ai-cybersecurity-labs.git
cd HIT-ai-cybersecurity-labs/project

Build and launch the containerized services:

docker-compose up --build

Access the interactive SOC dashboard in your browser:

http://localhost:8000
